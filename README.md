# Amazing Shopping

## Project Overview
Amazing Shopping is a responsive e-commerce website designed to showcase fashion, accessories, and home essentials through a clean and user-friendly interface.

## Features
- Responsive website layout
- Product browsing interface
- Organized product categories
- User-friendly navigation
- Clean and modern design

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Project Purpose
Developed to strengthen frontend development skills, practice responsive web design, and create an engaging online shopping interface.

## Live Demo
https://bhagya147.github.io/Thrilley-shopping/

## Installation and Usage
1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
